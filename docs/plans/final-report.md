## جولة التحقق الثانية (8 نوفمبر): ما كان ناقصاً وأُكمل

قارنتُ الدراسة سطراً بسطر بالكود، وأعدتُ قراءة خدمات المراحل 3 إلى 8. ما وُجد وأُكمل، كله باختبارات وفحص في البرنامج الحقيقي:

| ما كان ناقصاً | ما أُنجز |
| --- | --- |
| تغيّر سعر الشراء: «السعر المقترح» وزر «طبّق» (الدراسة) | عند الاستلام: سعر بيع مقترح يحفظ الهامش، مقرّب كما تُكتب الأسعار (0.5 أو 1 أو 5 دج)، لا يتجاوز السعر الرسمي. «طبّق» يغيّر السعر في الصندوق (فيتبعه قارئ الأسعار وقائمة الميزان). مثال حقيقي: بسكويت 38 ← 46 دج شراءً، المقترح 61 دج |
| «ملصقات للطباعة» | كل سلعة تغيّر سعرها (بـ«طبّق» أو من نموذج السلعة) تنتظر في صفحة الملصقات: «أضف ملصقاتها» |
| انقطاع الكهرباء: «السلة المفتوحة تعود» | التذكرة المفتوحة تُحفظ في ملف على القرص عند كل تغيير، وتعود بعد إعادة التشغيل لنفس العامل في نفس يوم المحل. **جُرّب بقتل البرنامج وسط تذكرة**: عادت. (التخزين العادي للمتصفح فشل في هذا الاختبار، فلم يُعتمد) |
| بريدي باي: «يعرض رمز المحل» | صورة رمز بريدي باي الخاص بالمحل تُضاف مرة في الإعدادات › شاشة البيع، وتظهر كبيرة في نافذة الدفع |
| السنتيم على قارئ الأسعار | «2.5 ألف» تحت 25 دج على اللوحة والهاتف حين يكون الخيار مفعّلاً |
| أسباب الخسارة: «منتهي» | سبب «منتهي الصلاحية» في تعديل المخزون |
| أسماء المورد من ملفات Excel («لاحقاً» في المرحلة 4) | ملف المورد يُطابق بأسمائه المعروفة، وحفظ الطلبية يتعلّم أسماء ملفه |

**أخطاء وُجدت وأُصلحت:**
- **تعديل المخزون للسلع بالوزن كان يقرأ الرقم بالغرام:** «2» لإزالة 2 كغ طماطم تالفة كانت تُزيل 2 غ. الآن الكمية بالكيلوغرام (2 أو 2,5)، والمخزون الحالي والجديد بالكغ، والحد الأدنى في القائمة بالكغ.
- **ترقيم الكارني القديم (KO-…) والاستلام (R-…)** كان يعدّ الأسطر، فسطر محذوف يجعل الرقم التالي مكرراً ويمنع الإدخال. الآن يتبع أعلى رقم.
- **الخادم المحلي على حواسيب Windows:** كان يأخذ أول عنوان، وقد يكون محوّلاً افتراضياً (WSL، Hyper-V، VirtualBox، VPN) فلا يصل الهاتف. الآن عنوان WiFi أو الكابل أولاً، والمحوّلات الافتراضية تُترك، ويختار المالك إن وُجدت عدة شبكات. ونصيحة جدار الحماية («السماح» للشبكات الخاصة) ظاهرة.
- **فحص النصوص:** اختبار جديد يتأكد أن كل مفتاح نص يُبنى أثناء التشغيل (المواسم، الأشهر الهجرية، أقسام الإعدادات…) ونصوص التذاكر والأوراق موجودة باللغات الثلاث.

## كيف تجربه على جهازك

```bash
cd afus-hanout
git checkout main && git pull
npm ci                    # يحتاج cdn.sheetjs.com لحزمة xlsx
npm run electron:dev      # البرنامج مع خادم التطوير
```

- **المحل التجريبي:** في أول شاشة اختر «جرّب المحل التجريبي». المالك «إسلام نوري» ورمزه **1111**. «إعادة العرض للبداية» يعيده كما كان.
- **مثبّت Windows** (على Windows): `npm run electron:build:win -- --publish never` ← `release/Afus Hanout Setup 1.0.0.exe`.
- **تطبيق الهاتف:** `cd mobile && npm ci && npx expo start`، ثم امسح رمز Expo بتطبيق Expo Go. الهاتف والحاسوب على نفس WiFi. في البرنامج: الإعدادات › الهاتف وقارئ الأسعار › شغّل، ثم «أضف جهازاً» وامسح الرمز من التطبيق.
- **قارئ الأسعار:** لوحة عند الرفوف تفتح العنوان المكتوب تحت رمز QR (`http://<عنوان الحاسوب>:4560/kiosk`) وتكتب الأرقام الستة.
- **الاختبارات:** `npm test` · `npm run lint` · `npm run typecheck`.

## ما يبقى عليك (لا أستطيع فعله من هنا)

1. **حذف 5 فروع مؤقتة** في afus-hanout. تحققتُ أن كل ملف فيها موجود في تاريخ `main` (لا يضيع شيء)، لكن الجلسة رفضت الحذف لأنه فعل لا رجعة فيه على GitHub. من جهازك:
   ```bash
   git push origin --delete tmp-import-0 tmp-import-1 tmp-import-2-0 tmp-import-2-1 tmp-import-2-2
   ```
   وإن أردت، فروع المراحل المدموجة أيضاً.
2. **GitHub Actions** لا تبدأ أي مهمة على المستودع (الفوترة أو الإعدادات): لهذا كانت كل الفحوص محلية.
3. **صياغة شاشة الزكاة** تُراجع مع مختص قبل النشر (قرار مفتوح في الدراسة). الشاشة تقول إنها تقدير وليست فتوى.
4. **الميزان:** اختيار العلامة الأكثر بيعاً عند موزعي الأجهزة وشراء ميزان مع دليل بروتوكوله؛ بعدها نبرمج الإرسال المباشر ونضبط شكل الملف (الفاصل، الأعمدة، الأسماء العربية).
5. **بريدي باي:** سؤال بريد الجزائر عن واجهة ربط؛ حتى ذلك الوقت التأكيد برسالة SMS.
6. **قارئ الأسعار:** لوحة أندرويد عادية مع ماسح، أم جهاز مخصص.
7. **الشعار والتسعير**، و**ثلاثة حوانيت تجريبية**، و**الفيديو** (مرحلة 9 في الدراسة، كلها عندك).
8. **إن أردت** أن تعمل `npm ci` هنا في الجلسات القادمة: السماح بـ `cdn.sheetjs.com` في شبكة البيئة.

## ما تُرك عمداً أو لم يُنجز

- **قراءة الفواتير والكارني بالتصوير ومشروع Supabase:** تُركت بقرارك (العمل بلا إنترنت تماماً). بدلها الإدخال السريع بذاكرة المورد والكارني القديم اسماً بعد اسم.
- **تعلّم أسماء المورد من ملف Excel:** لاحقاً؛ الذاكرة تمتلئ اليوم من الإدخال.
- **الإرسال المباشر للميزان:** بعد شراء الميزان (لا نبرمج بروتوكولاً دون جهاز).
- **عدة صناديق في محل واحد:** لاحقاً، كما في الدراسة.
- **المراجعة المستقلة بوكلاء:** لم تكتمل للمراحل 3 إلى 8 بسبب حد الاستعمال؛ عوّضتها بالاختبارات قبل الكود، والفحص في البرنامج الحقيقي، ومراجعتي الخاصة (مثلاً: رمز الاقتران يُلغى بعد 5 محاولات خاطئة). أنصح بمراجعة مستقلة للخادم المحلي (`electron/server/localServer.js`) قبل محل حقيقي.
- **ملاحظات على Boutique** (لم تُصلح فيه، كما طلبت): في `docs/boutique-notes.md`.
